[Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests/)

Go version: `go1.23.0 darwin/arm64`

## Run

```bash
go run <directory>
# Example:
go run ./1_hello_world
```

## Test

```bash
go test <directory>
# Example:
go test ./1_hello_world
```
